# qrcodeScanner
### QR code scanner

[qrcodeScanner](https://jebance.github.io/qrcodeScanner/) is a Progressive Web Applications (PWA) that can be installed from a browser directly to your device running Android, iOS, Linux, Windows, etc.

Application for scanning and recognizing QR codes.

The program and its open source code are provided to the public on an “as is” basis. The developer will not bear any responsibility for damages resulting from the use of the program or its source code.

Third-party products used:
- [html5-qrcode](https://github.com/mebjas/html5-qrcode) library by [Minhaz](https://github.com/mebjas)
- [Flaticon](https://www.flaticon.com/free-icon/barcode-scan_10043263) icon by [Abdul-Aziz](https://www.flaticon.com/authors/abdul-aziz)
